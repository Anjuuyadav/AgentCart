# AgentCart

## Tagline

The AI-native merchant that can actually transact.

## Problem

Traditional merchant stores are designed for human buyers.
AI buyers need machine-readable commerce capabilities and safe
transaction execution.

## Solution

AgentCart enables an AI buyer to discover products, receive
personalized recommendations and upsells, build a cart and
complete a Razorpay transaction while enforcing deterministic
financial policies and maintaining a complete audit trail.

## Core Flow

Customer
→ AI Buyer
→ Product Discovery
→ Recommendation
→ Upsell
→ Policy Engine
→ Approval
→ Razorpay
→ Webhook
→ Order Complete
→ Audit
→ Analytics
